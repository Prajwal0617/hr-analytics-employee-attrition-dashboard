# hr-analytics-employee-attrition-dashboard
## Project Overview

This project analyzes employee attrition and workforce trends using SQL, Python, and Power BI to generate business insights and HR KPI dashboards.

## Tools Used

- Python
- SQL (MySQL)
- Power BI
- Excel

- ## Dashboard Features

- Attrition Analysis
- Employee Demographics
- Salary Analysis
- Overtime Analysis
- Department Insights
- Interactive KPI Dashboard

- ## Key Insights

- Higher attrition observed among overtime employees
- Lower salary groups showed higher attrition trends
- Certain job roles had lower satisfaction scores
